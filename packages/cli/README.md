# @openpromises/cli

The `openpromises` command: `validate`, `new`, `review`, `check-quote`, `deadlines`, `lint`, `migrate` and `stats` for an [OpenPromises](https://github.com/xternal/openpromises) content folder. Start with the [two-minute example](https://github.com/xternal/openpromises#two-minute-example); the format is in [docs/FORMAT.md](https://github.com/xternal/openpromises/blob/main/docs/FORMAT.md).
