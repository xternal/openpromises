# Security

OpenPromises makes no network calls and stores nothing about the people who use it, so its main risks are in the files it reads and writes: a crafted card, configuration or YAML file.

**Reporting a problem:** please report it privately through GitHub (the repository's Security tab, "Report a vulnerability"), not in a public issue. You will hear back within a week. Please give us a reasonable time to fix it before you make it public.

**Supported versions:** the latest 0.x release.
